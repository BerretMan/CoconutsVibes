# 🌴 **Coconuts Vibes** 

<p align="center">
<img src="image/logo.png" alt="Coconuts Vibes Logo" width="200"/>  
</p>

**Coconuts Vibes** is a Discord music bot that scrapes Youtube or Google Drive music to play on Discord voice channel.

## Dependencies
- **Discord.py** For the Discord API wrapper and Slash Commands
- **Pytube** To handle Youtube video scraping
- **FFmpeg** To process voice


---
## **Features**  
- Download music directly from YouTube or Google Drive
- Control the speed of the music
- Support playing an entire playlist 
- It uses Discord Slash Commands


## **Installation**
1. Clone the repo
2. Add personal discord Token in TOKEN.TXT 
3. Put your GUILD_ID (right click on your discord server then copy Server ID) in GUILD_ID (app.py)
